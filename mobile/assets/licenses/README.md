# FairBill artwork

FairBill’s native illustrations and 24-unit outline icons are original project artwork. The receipt and check motifs carry across the app, with vector geometry that scales without raster assets.

## Typography and motion

The header and case list use a semibold subset of [Google Sans](google-sans.txt). The bundled subset includes the rupee sign.

FairBill bundles [Crimson Pro](crimson-pro.txt) for editorial headings and letters, [PT Sans](pt-sans.txt) for controls and body text, and [Source Code Pro](source-code-pro.txt) for amounts and source excerpts. Each linked file contains the applicable SIL Open Font License.

[Alloy Accordion](https://www.framer.com/marketplace/components/alloy-accordion/) informed the one-open-source interaction in bill review and proof. [Text Reveal](https://www.framer.com/marketplace/components/xDgp5el32fHNjPkyEMsb/) and [Number Ticker](https://www.framer.com/marketplace/components/TUnoGvWgoxN57AQih7DR/) informed the evidence and revision transitions. FairBill fades in the exact amount and keeps it available to assistive technology. The loading bar reflects the real request state.
